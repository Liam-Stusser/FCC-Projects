# 📁 FreeCodeCamp Projects Repository

This repo holds all of my completed [FreeCodeCamp](https://www.freecodecamp.org/) certification projects. It's a place to keep track of my progress, share what I’ve built, and make it easier to look back at how far I’ve come.

All of the projects here passed their original certification requirements when submitted. Some were updated afterward to improve how they look or function, so a few might not align 100% with FCC’s original constraints anymore — but that’s just part of growing and refining things.

I'm using **Visual Studio Code** and the **Live Server extension** to run HTML and CSS projects locally.

## 📝 Notes on FEL Projects

The **Front End Libraries** projects may differ slightly from the versions submitted to FreeCodeCamp, as their platform requires projects to be built on **CodePen**. Running React, Redux, and React-Redux outside of CodePen required a custom `webpack.config.js` and some modifications.

While using **Redux** for simpler apps may be overkill, the intention is to **practice and master the tools** through repeated exposure and usage in multiple contexts.
