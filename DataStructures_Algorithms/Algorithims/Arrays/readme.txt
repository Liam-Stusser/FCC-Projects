This folder contains a single C# file that demonstrates common sorting algorithms on linear arrays.

Unlike the other folders in the Data Structures & Algorithms section, which each provide examples in Python, JavaScript, and C#, 
this one is limited to C#. The reason isn’t to simplify things for others, but rather because I wanted a concise reference for myself. 
Writing these algorithms in one statically typed language helped me reinforce the concepts more clearly.

I chose C# specifically because it provides a stronger, more explicit view of what’s happening “under the hood” compared to dynamic languages 
like Python or JavaScript, which can sometimes obscure the underlying mechanics. 
These implementations are meant to be simple, straightforward, and easy to revisit later if I need a refresher on these sorting techniques.
